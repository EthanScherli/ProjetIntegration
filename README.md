# Installation et Démarrage

## Prérequis

### Assurez-vous d'avoir installé les éléments suivants sur votre machine :

**Node.js (et npm, qui est inclus par défaut)**

**Git**

## 1. Cloner le dépôt

**git clone https://github.com/EthanScherli/ProjetIntegration**

**cd ProjetIntegration**


## 2. Installation du Backend

### Se rendre dans le dossier du serveur
**cd server**

### Installer les dépendances
**npm install**

## 3. Installation du Frontend

### Se rendre dans le dossier de l'application

**cd my-app**

### Installer les dépendances

**npm install**

## 4. Lancement du projet

### Retourner à la racine du projet et lancer le projet

**npm run dev**


## 4. Configuration du Raspberry Pi Pico W

Ce dossier contient les scripts pour lire et envoyer les données des capteurs.

Transférez les fichiers contenus dans scriptsPicoW sur votre Raspberry Pi Pico W. Vous pouvez utiliser un IDE comme Thonny.

Adapter les variables de configuration dans les scripts du Pico W avant de les exécuter.
